# AI/ML Projects

A collection of my AI/ML projects, each in its own subfolder with its own
README, dependencies, and (where applicable) deployment config.

## Projects

### [`zodiac-movie-chatbot/`](./zodiac-movie-chatbot)
An intent-classification chatbot (TF-IDF + Logistic Regression) that
identifies whether you're asking for your zodiac sign or a movie
suggestion, then asks follow-up questions to collect whatever it needs
before answering. Includes both a Flask app and a Streamlit app sharing
the same dialogue engine. See the [project README](./zodiac-movie-chatbot/README.md)
for architecture details, local setup, and deployment instructions.
